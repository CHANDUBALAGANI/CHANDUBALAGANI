# ⭐ Featured Project

# 🛍️ **ShopMind AI**

## AI-Powered E-Commerce Platform

`Django` · `PostgreSQL` · `Groq AI` · `Cloudinary` · `Render`

</div>

### 🚀 What I Built

A full-stack e-commerce application combining a complete online shopping experience with an **AI shopping assistant**.

### ✨ Key Features

**🔐 Authentication**  
Registration, login, logout and protected checkout.

**🛍️ Products**  
Categories, product listings, search, pricing, images and stock.

**🛒 Shopping**  
Cart, quantity management and wishlist.

**📦 Orders**  
Checkout, order creation, order history and order details.

**🤖 AI Assistant**  
Natural-language product recommendations based on available inventory.

**☁️ Deployment**  
PostgreSQL database, Cloudinary media storage and Vercel deployment.

---

## 🤖 AI Shopping Assistant

Users can make natural requests such as:

```text
"I need a laptop under 80000"
```

```text
"Which mobile is under 50000?"
```

The assistant uses the available store inventory to provide relevant recommendations.
