# 🛍️ ShopMind AI

### AI-Powered E-Commerce Platform

</div>

**ShopMind AI** is my main full-stack project, built with Django and enhanced with an AI shopping assistant.

### What it includes

- 🔐 User registration and authentication
- 🛍️ Product browsing and categories
- 🔎 Product search
- 🛒 Shopping cart
- ❤️ Wishlist
- 📦 Checkout and order management
- 📊 Product stock management
- 🖼️ Cloudinary image storage
- 🤖 AI shopping assistant using Groq API
- 💰 Budget-based product recommendations
- ☁️ PostgreSQL database and cloud deployment

### Tech Stack

`Python` `Django` `PostgreSQL` `HTML` `CSS` `JavaScript` `Bootstrap` `Groq AI` `Cloudinary` `Render`
