# 🚀 Featured Project

## 🛍️ ShopMind AI

### AI-Powered E-Commerce Platform

</div>

**ShopMind AI** is my main full-stack project, built with **Django, PostgreSQL, Cloudinary, and Groq AI**.

The application combines traditional e-commerce functionality with an AI shopping assistant that helps users discover products based on their requirements and budget.

### ✨ Key Features

- 🔐 User registration and authentication
- 🛍️ Product browsing and categories
- 🔎 Product search
- 🛒 Shopping cart
- ❤️ Wishlist
- 📦 Checkout and order management
- 📊 Product stock management
- 🖼️ Cloudinary product image storage
- 🤖 AI shopping assistant using Groq API
- 💰 Budget-based product recommendations
- 🗄️ PostgreSQL database
- ☁️ Render deployment

### 🤖 AI Shopping Assistant

The assistant can understand requests such as:

```text
I want a mobile
```

```text
I need a laptop under 80000
```

```text
Show me electronics
```

```text
Which mobile is under 50000?
```

`Python` `Django` `PostgreSQL` `HTML` `CSS` `JavaScript` `Bootstrap` `Groq AI` `Cloudinary` `Render`
